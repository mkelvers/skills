# Reference images

These are screenshots the user likes, with a note on what each one teaches. Before designing a page, open the ones that relate to it with the Read tool and look at them yourself. The notes help, but they don't replace looking.

`felt-homepage-desktop.png` is the design the user accepted on 2026-11-08, a personal homepage. The page is one colour surface with a short block of small text and a crafted felt flower border along the bottom edge. Take from it how obvious the page's job is at a glance (who this is, how to reach them) and how the decoration stays out of the way. `felt-homepage-mobile.png` is the same page at phone width. The content and order stay the same in one column, with nothing tucked behind a menu.

`felt-texture-moodboard.png` is a screenshot of three felt designs from a social post. The user liked the blue one on the right, with the flowers along the bottom. The red page, with a big whale beside the headline, is the busy direction they rejected.

There are no shop, product or app references yet. When working on something like that, ask the user for a few screenshots of sites they admire and save them here. Name each file so it says what it shows, and add a few sentences on what to take from it (structure, hierarchy, tone) and what to leave (brand, content).
